# Security policy

## Reporting a vulnerability

If you have found something with a security or privacy dimension, please report it privately rather than posting it in the community or in a public issue.

Email: support@shackademy.com

Please include what you found, the steps to reproduce it, the browser and extension version, and what you think the impact is.

You will get an acknowledgement within five working days. We will tell you what we intend to do and roughly when, and we will let you know when a fix has been released.

This is a small project. There is no bug bounty and we cannot offer payment, but reports are taken seriously and we would much rather hear from you than not.

## Please do not

- Post details publicly before we have had a chance to respond.
- Test against another member's account or data.
- Attempt anything against Voyant's own systems. This extension is not affiliated with Voyant, and issues in their platform should go to them directly.

## Supported versions

Only the current published version receives fixes. Because updates are delivered automatically by Chrome and Firefox, almost everyone is on it. If you are running something older, restart your browser and it should update.

## Scope

In scope:

- Anything that would let the extension read, transmit or expose the plan data on the page.
- Anything that would let a third party inject content through the extension.
- Anything that causes the extension to run on sites other than planwithvoyant.co.uk.
- Anything in the extension's permissions that is broader than it needs to be.
- Compromise or misuse of the store listings or the update mechanism.

Out of scope:

- Issues in Voyant itself.
- Issues in Chrome, Firefox or the extension stores.
- Reports generated by an automated scanner with no demonstrated impact.
- Help text that you think is wrong. That matters, but it goes through the routes in the README instead.

## What the extension can access

The extension runs only on planwithvoyant.co.uk. On that page it reads the structure of the page in order to find the right places to attach guidance.

It does not read the values you have entered, does not store anything about your plan, and does not send data to Shackademy or to anyone else. There is no server component and no analytics.

You can verify all of this in the source in this repository. `manifest.json` declares the permissions the extension requests, and `content.js` is where the page interaction happens.

Our privacy policy is at https://shackademy.com/privacy
